# 🇷🇴 Black Friday бот — отслеживание цен в магазинах Румынии

Облачный бот, который каждые ~10 минут проверяет нужные вам товары в румынских интернет-магазинах и на агрегаторах цен. Как только что-то подходит под ваши критерии, он сразу пишет в Telegram.

* **Бесплатно и в облаке**: работает на GitHub Actions, компьютер включённым держать не нужно.
* **Ваши критерии**: максимальная и минимальная цена, минимальная скидка, обязательные и запрещённые слова, конкретные магазины или категории, только товары в наличии.
* **Без спама**: сообщает о новом подходящем предложении, о снижении цены (по умолчанию от 2%), о возвращении товара в наличие. Повторов нет.
* **Защита от «фейковых» скидок**: бот хранит историю цен и показывает минимальную цену, которую видел за всё время.
* **Управление из Telegram**: `/add`, `/list`, `/set`, `/del`, `/top`, `/stores`.
* **Охват**: крупные магазины напрямую, агрегаторы цен (compari.ro и др., сотни магазинов), любой магазин на Shopify / WooCommerce / VTEX / Magento, любая страница товара со стандартной разметкой (schema.org).

## Установка (≈5 минут)

### 1. Создайте Telegram-бота
1. Откройте в Telegram [@BotFather](https://t.me/BotFather) → `/newbot` → придумайте имя.
2. Скопируйте токен вида `123456789:AAH...`.

### 2. Добавьте токен в GitHub
Репозиторий → **Settings → Secrets and variables → Actions → New repository secret**
* `TELEGRAM_BOT_TOKEN` — токен из шага 1 (обязательно)
* `TELEGRAM_CHAT_ID` — необязательно. Если не задан, бот привяжется к первому, кто напишет ему `/start`.

### 3. Включите проверки
Вкладка **Actions** → если GitHub просит, нажмите *I understand my workflows, enable them*. Затем откройте workflow **watch** → **Run workflow**. Дальше он сам запускается каждые 10 минут.

### 4. Напишите своему боту `/start`
Бот привяжется к вашему чату и покажет меню с кнопками:

* **➕ Добавить товар**: напишите, что искать, латиницей, как на сайте магазина (`iphone 16 pro 256gb`, `rtx 5070`, `aspirator dyson v15`), или пришлите ссылку на конкретный товар.
* В карточке товара всё настраивается кнопками: **💰 макс. цена**, **💵 мин. цена**, **🏷 скидка %**, **🚫 исключить слова**, **✅ обязательные слова**, **🏪 магазины** (отмечаются галочками), **📦 только в наличии**, **⏸ пауза**, **📊 топ-10 сейчас**, **🗑 удалить**.
* **📋 Мои товары**: список; нажмите на товар, чтобы изменить условия.

Каждый запуск в GitHub после проверки цен ещё ~8 минут слушает Telegram. Запуски идут друг за другом, поэтому бот отвечает на кнопки почти сразу.

Опытным пользователям доступны и текстовые команды:

```
/add iphone 16 pro 256gb до 4800 -max -resigilat
/add rtx 5070 <3200 >2000 @pcgarage,emag,altex,compari
/add aspirator dyson %25 #home
/add https://www.emag.ro/.../pd/XXXX/ <2000
```

## Критерии (синтаксис `/add` и `/set`)

| Запись | Значение |
|---|---|
| `до 4800`, `<4800`, `max=4800` | максимальная цена, лей |
| `от 3000`, `>3000`, `min=3000` | минимальная цена (отсекает аксессуары) |
| `%20`, `скидка 20` | минимальная скидка, %: от старой цены магазина **или** от максимальной цены, которую видел бот |
| `-слово`, `-"два слова"` | исключить, если есть в названии |
| `+слово` | обязательное слово (если указано, слова запроса не требуются целиком) |
| `?lg\|sony\|samsung` | хотя бы одно из |
| `@emag,altex` / `^cel` | только эти магазины / кроме этих |
| `#electronics` | категории магазинов: electronics, pc, home, appliances, fashion, beauty, diy, toys, general |
| `!all` | показывать и товары не в наличии |
| `~` | нестрогий поиск: не требовать все слова запроса в названии |
| `https://...` | следить за конкретной страницей товара |

По умолчанию все слова запроса должны быть в названии товара (`256` совпадёт с `256GB`, но `16` не совпадёт с `16e`). Чехлы, плёнки, кабели и прочие аксессуары отсекаются, если такого слова нет в самом запросе.

Команды: `/list` · `/top N` (самые дешёвые сейчас) · `/set N до 4500` · `/pause N` · `/resume N` · `/del N` · `/stores` · `/status` · `/help`.

Пункты можно задавать и в [`config.yaml`](config.yaml): там же примеры и общие настройки.

## Если магазин блокирует облако

Некоторые крупные магазины (Altex, возможно eMAG) защищены Akamai и могут блокировать IP дата-центров, включая GitHub. Бот сам напишет «⚠️ … не отвечает», если магазин недоступен 6 проверок подряд. Цены этих магазинов при этом всё равно видны через агрегаторы (compari.ro). Варианты:

1. **Свой компьютер, Raspberry Pi или домашний сервер в Румынии** (надёжнее всего, домашний IP не блокируют):
   * через Docker: создайте файл `.env` со строкой `TELEGRAM_BOT_TOKEN=...` и выполните `docker compose up -d --build`;
   * или как self-hosted runner GitHub: *Settings → Actions → Runners → New self-hosted runner*, затем создайте переменную репозитория `RUNNER` = `self-hosted`. Те же проверки пойдут с вашего IP.
2. **Прокси**: секрет `BOT_PROXY` = `http://user:pass@host:port`; переменная `BOT_PROXY_STORES` = `altex,emag`, чтобы использовать прокси только для них. Чтобы экономить трафик, в `config.yaml` укажите `store_every: {altex: 3}`: такой магазин будет опрашиваться каждую 3-ю проверку.

## Диагностика

Workflow **diag** (*Actions → diag → Run workflow*) один раз опрашивает все магазины. Он сохраняет сырые страницы и отчёт в ветку `diag` и в Summary запуска: видно, какой магазин работает, сколько товаров найдено и каким способом.

Локально:
```bash
pip install -r requirements.txt
python -m bot stores                          # список магазинов
python -m bot search emag "iphone 16 pro"     # проверить один магазин
python -m bot search all "rtx 5070"           # все магазины
python -m bot product https://...             # цена со страницы товара
python -m bot run --dry-run                   # один цикл без отправки в Telegram
```

## Как это устроено

```
GitHub Actions (cron */10) ──► python -m bot run
   1. читает команды из Telegram (getUpdates)
   2. опрашивает магазины параллельно (curl_cffi с отпечатком Chrome, паузы между запросами)
   3. фильтрует по критериям, сравнивает с историей (ветка state → state.json)
   4. шлёт уведомления и сохраняет состояние обратно в ветку state
```

* `bot/stores/*.py` — адаптеры магазинов. Новый магазин — новый файл с классом `Store`, регистрация автоматическая.
* Если вёрстка магазина изменилась и его парсер ничего не нашёл, бот пробует универсальные способы: JSON-LD, микроразметку, встроенный JSON и эвристику по карточкам товаров.
* Состояние (история цен, что уже отправлено) хранится в ветке `state` одним коммитом, поэтому история репозитория не растёт.

Ограничения GitHub: запуски по расписанию иногда задерживаются на несколько минут. Для публичного репозитория минуты Actions бесплатны и не ограничены.
